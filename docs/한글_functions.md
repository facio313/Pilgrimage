## 공통 화면 셸

- 로그인 확인·오류, 일반 앱 화면, 공개 공유 경로를 포함한 모든 프런트엔드 화면 위에 공통 헤더를 표시한다.
- 헤더의 `← Bonifacio` 링크는 최소 48px 터치 타깃과 명확한 키보드 포커스를 제공하며, 같은 탭에서 `https://bonifacio.work/`로 이동한다.

## F01 · 테마 선택 (priority 1)

사용자가 여행 테마를 단일/다중 선택하면 해당 테마의 관광지 목록을 반환한다.

- 테마 (11개): 혼합, 자연, 유적, 도시, 축제, 레저, 쇼핑, 맛집, 캠핑, 의료/웰니스, 효도
- 테마 키 → `contentTypeId` 매핑은 `common/themes.py` Python dict 상수로 관리
- 캠핑·의료·효도는 KTO 별도 API 사용 (고캠핑, 의료관광정보, 무장애 여행 정보)
- 특정 지역 선택 시 지역 특화 테마 우선 추천

**KTO API**
- 기본 목록: 국문 관광정보 서비스 (KorService1)
- 지역 다양성: 지역별 관광 다양성
- 지역 기반: 기초지자체 중심 관광지 정보

## F02 · 여행 경로 구성 — 플로팅 메뉴 (priority 2)

카카오맵에서 관광 포인트를 클릭하면 주변 관광지가 플로팅 메뉴로 표시되고, 선택 시 최단 경로가 자동 계산된다.

- PostGIS `ST_DWithin`으로 반경 5km 이내 관광지 공간 쿼리
- 경로 알고리즘: Nearest Neighbor TSP 근사 (Python 서버사이드)
- 이동 수단별 속도/비용 가중치 분리 (F07 연동)
- 혼잡 예측 점수 높은 관광지는 경로 후순위 처리
- 카카오맵 Polyline으로 경로 시각화

**KTO API**
- 주변 추천: 관광지별 연관 관광지 정보
- 수요 가중치: 지역별 관광 자원 수요
- 혼잡도 회피: 관광지 집중률 방문자 추이 예측 정보

## F03 · 자동 여행 경로 추천 (priority 3)

사용자가 조건을 입력하면 스코어링 엔진이 최적 경로를 자동 구성한다.

**입력 파라미터**
- 여행지 개수 (N), 예산 상한 (원), 최소 평점, 최대 이동 거리 (km), 운영시간 고려 여부, 이동 수단 (F07)

**스코어링 공식**
```
score = w1·review_score + w2·(1/cost) + w3·(1/distance) + w4·congestion_penalty
```
가중치 w1~w4는 테마별 차등 적용, Python dataclass로 관리

**규칙**
- 운영시간 필터: 선택 날짜 기준 영업 중인 관광지만 포함
- 예산 초과 시 관광지 수 자동 감소 후 재시도

**KTO API**
- 캠핑 → 고캠핑 정보 조회서비스
- 의료 → 의료관광정보, 웰니스관광정보
- 생태 → 생태 관광 정보, 두루누비 정보 서비스
- 무장애 → 무장애 여행 정보
- 반려동물 → 반려동물 동반여행 서비스

## F04 · GPS 체류 인증 — 30분 룰 (priority 4)

관광지 반경 200m 이내 30분 이상 체류 시 방문 인증 부여. 인증자만 후기 작성 가능.

| 파라미터 | 값 |
|---------|---|
| 인증 반경 | 200m |
| 최소 체류 | 30분 |
| 이탈 허용 | 10분 (복귀 시 체류 연속 인정) |
| GPS 로그 간격 | 30초 |
| 위조 탐지 | 연속 로그 간 이동속도 200km/h 초과 → REJECTED |

**인증 상태**: `UNVISITED` / `CERTIFIED` / `REJECTED`

**웹 플랫폼 제약**
- 브라우저 탭 포그라운드일 때만 위치 수신 가능
- HTTPS 환경 필수 (Geolocation API Secure Context 강제)
- Page Visibility API로 탭 비활성 시 체류 타이머 일시정지
- 탭 이탈 시 경고 UI 표시 (`beforeunload`)

## F05 · 후기 시스템 — GPS 인증 전용 (priority 5)

`VisitLog.status == "CERTIFIED"` 인 사용자만 후기 작성 가능. 광고성 후기 원천 차단.

**후기 필드**
- 별점 (1~5), 텍스트, 소요 금액 (입장료·식비·기타), 방문 날짜 (visit_log FK 자동 추출), 사진 최대 5장

**표시 규칙**
- 플로팅 메뉴: 평점 높은 순 정렬
- GPS 인증 배지 표시
- 관광지별 평균 소요금액·평균 체류시간 자동 통계

후기 데이터는 F03 스코어링 엔진(`review_score`)에 활용된다.

## F06 · 경로 저장 / 공유 / 복제 (priority 6)

완성된 경로를 저장하고 경로 단위로 공유하거나 복제(fork) 후 수정 가능.

- 공유 링크: UUID 기반 shortlink (`/shared/:token`) — 비로그인 접근 허용
- 공개 / 비공개 설정
- 복제 시 `fork_from_id`로 원본 참조 보존
- 경로에 방문 인증 현황 (완료/미완료) 함께 표시
- 회고록 모드: 이미 다녀온 경로도 저장 가능

---

## F07 · 이동 수단 선택 및 비용 계산 (priority 7)

이동 수단 선택 시 해당 기준으로 경로 재계산 및 예상 비용 산출.

**수단**: 자차, 버스, 기차, 걷기, 자전거, 혼합

**비용 계산**
- 자차: `거리(km) ÷ 12(km/L) × 1,700(원/L)`
- 대중교통: 1km당 100원 추정
- 걷기/자전거: 0원

---

## F08 · 관광지 상세 정보 (priority 8)

관광지별 상세 페이지: 소개, 오디오 가이드, 사진, 후기, 비용 통계

**KTO API**
- 오디오 가이드: 관광지 오디오 가이드 정보
- 사진: 관광사진 정보
